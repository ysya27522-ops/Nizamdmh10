# النظام (Nizam) - تطبيق أندرويد

تطبيق أندرويد رسمي متكامل تم تطويره بلغة **Kotlin** وواجهة **Jetpack Compose** وقاعدة بيانات محلية **Room**، يجمع بين:
1. **مستعرض وإدارة الملفات السحابية (Google Drive Explorer)**:
   - استعراض المجلدات والملفات (ملفاتي، المشتركة معي، المميزة بنجمة، سلة المهملات).
   - مسار المجلدات التفاعلي (Breadcrumbs) وعرض الشبكة والقائمة.
   - عمليات إدارة الملفات الكاملة: إنشاء مجلد جديد، إنشاء مستند نصي، تعديل الاسم، النقل للمهملات، الاستعادة، والحذف النهائي.
   - محرك بحث متقدم مع فلاتر نوع الملف، والمالك، وتاريخ التعديل.
   - قارئ المستندات المدمج مع إحصاء الكلمات وخيارات النسخ.
2. **وثيقة النظام الدستوري العربي الإسلامي**:
   - التقرير التوثيقي الكامل للأركان والمبادئ الخمسة (الحاكمية، الشورى، العدل والمساواة، عقد البيعة، الرقابة والمحاسبة).
   - مصفوفة السلطات الثلاث (التشريعية، التنفيذية، القضائية) وقضاء المظالم.
   - الوثائق التاريخية المرجعية (صحيفة المدينة، خطبة حجة الوداع، عهود الخلفاء).
   - حماية المقاصد الشرعية الخمسة (حفظ الدين، النفس، العقل، النسل، المال).
   - خيارات التصدير المباشر كملف Google Doc إلى ملفاتي في Drive ونسخ Markdown.
